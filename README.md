# 🏡 HomeStyle

**A Flutter-Based Furniture and Home Decoration Application**

HomeStyle is a mobile application designed to make furniture shopping and home decoration easier. It allows users to explore furniture products, browse different categories, manage favorites, and add products to their shopping cart.

The project also includes an AI-powered room design feature that helps users explore creative interior design ideas.

## ✨ Features

- User Registration and Login
- Browse Furniture Products
- Product Categories
- Product Details
- Favorites Management
- Shopping Cart
- AI-Powered Room Design
- User Account Management

## 🛠️ Technologies Used

- **Frontend:** Flutter & Dart
- **Backend:** PHP
- **Database:** MySQL
- **Local Storage:** SQLite & SharedPreferences
- **AI Backend:** Python & FastAPI
- **Development Environment:** Android Studio, Visual Studio Code, XAMPP

## 📁 Project Structure

- `lib/` – Flutter application source code
- `assets/` – Application images and resources
- `android/` – Android platform files
- `ios/` – iOS platform files
- `windows/` – Windows platform files
- `homestyle_api/` – PHP backend and API
- `ai_backend/` – AI room design backend
- `database/` – Database structure

## 🚀 Getting Started

1. Clone the repository.
2. Install Flutter dependencies using `flutter pub get`.
3. Configure the PHP backend using XAMPP.
4. Import the database structure into MySQL.
5. Configure the API base URL in the Flutter application.
6. Set up the Python AI backend and install its dependencies.
7. Run the application using `flutter run`.

## 🎓 Project Purpose

HomeStyle was developed as a university project to demonstrate practical skills in mobile application development, backend integration, database management, and AI-powered features.
